# Changelog

All notable changes to `leos-mels9ka/yii2-monolog2` will be documented in this file.

Updates should follow the [Keep a CHANGELOG](http://keepachangelog.com/) principles.

## 2.1.0 - 2026-11-24

### Added
- Support php 8.4

### Changed
- Minimum php version is 8.0
- Nullable parameters of `Yii2Monolog::getLogger()` and `HandlerFactory::make()` are declared explicitly

### Removed
- Dependency on `tightenco/collect`

## 2.0.0 - 2021-10-26

### Added
- Support php 8.0
- Support monolog 2.0

### Changed
- Migrate to `github action`
